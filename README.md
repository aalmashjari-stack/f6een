# فطين

لعبة أسئلة عربية جماعية تُلعب على شاشة واحدة كبيرة، يشغّلها شخص واحد كحكم.

مصدر الحقيقة لقواعد اللعبة والشاشات: [`docs/SPEC.md`](docs/SPEC.md).

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`.

### الفتح على التابلت

خادم التطوير يستمع على الشبكة المحلية. عند التشغيل يطبع سطرين:

```
Local:   http://localhost:5173/
Network: http://192.168.x.x:5173/
```

افتح عنوان `Network` في متصفّح التابلت — بشرط أن يكون على نفس شبكة الواي فاي.
أضِف الصفحة إلى الشاشة الرئيسية لتعمل بملء الشاشة بلا شريط عناوين.

### نسخة ثابتة (بلا خادم تطوير)

```bash
npm run build
```

تُنتج مجلّد `dist/` يعمل من أي مضيف ثابت أو من الملف مباشرة.

## وضع الاختبار السريع

أضِف `?fast` للرابط لتقليص كل المؤقتات إلى العُشر — للتنقّل السريع بين الشاشات أثناء التجربة، لا للّعب:

```
http://localhost:5173/?fast
```

## ما هو مبنيّ الآن

شاشات اللعب الست من SPEC.md، بجلسة كاملة تعمل من البداية للنهاية:

| الشاشة | الحالة |
|---|---|
| الإعداد (الفرق واللاعبون والقرعة) | ✅ |
| ١ العجلة | ✅ |
| ٢ سؤال الجولة الجماعية | ✅ |
| ٣ كشف وتنقيط الجولة الجماعية | ✅ |
| ٤ اختيار لاعبَي الديربي | ✅ |
| ٥ كشف وتنقيط الديربي | ✅ |
| ٦ الحق ما تلحق | ✅ |
| ٧ الفاصل | ✅ |
| ٨ الختام | ✅ |
| فاصل التعادل | ✅ |

**غير مبنيّ عمداً:** التسجيل، الشراء، الخادم. كل شيء يعمل محلياً بلا إنترنت.

## البنية

```
src/
  game/        منطق اللعبة الخالص (بلا واجهة)
    types.ts     الأنواع
    bank.ts      قراءة بنك الأسئلة وفهرسته
    draw.ts      خوارزمية السحب (القسم ٨ من SPEC)
    session.ts   الثوابت وإنشاء الجلسة والذاكرة
    reducer.ts   كل انتقالات الحالة
  components/  عناصر مشتركة (العجلة، المؤقت، شريط النتيجة)
  screens/     شاشة لكل مرحلة
  lib/         الحساب والقاعدة (supabase, auth, games, admin)
  admin/       لوحة الإدارة — صفحة مستقلّة، لا تُحمَّل مع اللعبة
  theme.css    الهوية البصرية (القسم ١١)
data/          بنك الأسئلة — للقراءة فقط
assets/        الشعار والأيقونة — معتمدة نهائياً
supabase/      مخطّط القاعدة وهجراتها
```

## لوحة الإدارة

`/admin.html` — صفحة ثانية في نفس البناء: الحسابات وأرصدتها، الجلسات،
أكواد الهدية، وبلاغات الأسئلة. صلاحيتها صفٌّ في جدول `admins` داخل القاعدة
لا شرطٌ في الواجهة، والتفاصيل في [`supabase/README.md`](supabase/README.md).

## قرارات معمارية مثبّتة

- **سحب مسبق لكل أسئلة الجلسة عند إنشائها** — ٤٠ سؤالاً احتياطاً للحق ما تلحق، والباقي عند كل لفّة. الجلسة تعمل كاملة بلا إنترنت لأن واي فاي المجلس غير موثوق.
- **الحفظ المحلي مستمر** — أي انقطاع أو إغلاق يرجع لنفس الجلسة بنفس النقاط والأسئلة، ضمن نافذة ٢٤ ساعة.
- **`used_question_ids` محفوظة محلياً** في `localStorage` — تُزامَن مع الخادم لاحقاً عند بناء الحسابات.
